One satirical sentence, under 320 characters: roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. A judge model reads the entries two at a time and picks the one with the sharper bite.

> Congress can write 400 pages of law telling algorithms how to behave, but the senator who sponsored the bill had to ask an intern to turn it into a PDF.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the roast to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
